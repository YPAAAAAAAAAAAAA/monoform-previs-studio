# monoform-previs-studio

A clean-room, from-scratch re-implementation of the idea behind **[guiyi-xi/monoform-previs-studio](https://github.com/guiyi-xi/monoform-previs-studio)** by [@guiyi-xi](https://github.com/guiyi-xi). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
